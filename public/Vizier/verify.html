Run Vizier's verification checks in your browser.

What is this?

This page tests Vizier's code in your browser. Run checks reads what the solver is given: where each value is stored, what each case declares, the shader text each case generates, and the equations the panel prints. It does not run the solver. The other two buttons do, on your GPU.

Everything here is code verification, asking whether the code solves the equations it states. Whether those equations describe a real flow is validation, which Vizier does not claim. The colors, hatching and arrows are checked by eye against the legend, and advection, the rate laws and most other terms are tested only by every case running without blowing up.

Runs every check in the table below, one at a time, in under twenty seconds. The page stops responding while a check runs; if the browser asks, choose to wait.
Needs WebGPU. Runs each case for two seconds of simulated time and fails any whose fields reach NaN, infinity or a million. It starts with the magnetic wake at a hundred times its field strength, which has to fail, to show that a blow-up is caught.
Needs WebGPU. Compiles every case's shader, then solves two problems with exact answers, a sine wave of temperature decaying between cold walls and flow down a straight channel. Each must match to within 0.0001.
